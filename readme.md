## Overview

**US Housing Market Analysis Dashboard**:

**Project Description**:
This Streamlit dashboard analyzes housing and income data from across U.S. cities to provide insights into the housing market trends, income distribution, and the impact of various factors on housing prices. It includes interactive visualizations and predictive modeling using Prophet.
**Project Goals**:
- Indentify top affordable cities for housing
- Identify cities to avoid for housing
- Use multiple sets of data to analyze housing trends
- Provide a user-friendly interface for data exploration
- Visualize trends with interactive charts

## Instructions for Build and Use

Steps to build and/or run the software:

1. Clone the repository
2. Install the required packages
3. Run the Streamlit app with the command `streamlit run main.py`

Instructions for using the software:

1. Explore the dashboard to view various visualizations
2. Use the visual charts to analyze housing trends
3. View the predictive model results for future housing trends

## Development Environment 

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Python 3.10 or higher
* streamlit
* pandas
* plotly
* numpy
* prophet (Facebook Prophet)
